# CloakIMG Air final controls and acceptance — 2026-10-30

The public site and complete editor now use Air 1.3.1. This closes the implementation scope parked during the earlier five-site rollout. Evidence is split into the public, editor, precision, assets, runtime and cleanup checkpoints linked below; those dated checkpoints retain their original limitations rather than being rewritten as retrospective passes.

The final piece replaces the batch recipe's custom menu with the existing Base UI adapter, adds keyboard reorder, retains expansion by step identity, and keeps a running batch usable when resizing into phone/landscape layouts. Batch download buttons use neutral Air ink and correct target sizes. Duplicate utility classes and competing AI badge/error colours are removed. The editor header and dialog headings reflow at enlarged text. Remaining literal radii now reference their identical canonical Air tokens. Recovery boundaries stay standalone so a shared-modal failure cannot break recovery; both use the Air dialog/sheet geometry, scrollable details, keyboard focus containment and explicit recovery actions.

A real cancellation probe found that an active Subject scope restarted detection after Cancel reset it to idle. The host now latches the existing pause state before cancelling; explicit Enable AI resumes. The regression test mounts the real scope row with the consent host, rather than testing only the service. This preserves cached bytes and the user's prior consent.
